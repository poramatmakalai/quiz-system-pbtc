# Local Quiz Management System

ระบบเกมตอบคำถามแบบครบวงจร รันบนเครื่องได้ทันที **ไม่ต้อง Deploy / ไม่ต้องซื้อ Hosting / ไม่ต้องจด Domain**

ธีมสีฟ้า–ขาว ตามวิทยาลัยเทคนิคเพชรบุรี พร้อมโลโก้ เหมาะกับจอสัมผัส / บูธประชาสัมพันธ์

## คุณสมบัติหลัก

### Player Website (`/player`)
- หน้าเริ่มเกม กรอกชื่อ (ไม่บังคับ) แล้ว**เลือกหมวดหมู่**เอง
- แสดงหมวดหมู่ตามลำดับที่ Admin จัด (มีปุ่มดูเพิ่มเติม)
- 1 รอบ = 1 หมวดที่เลือก (ไม่ปะปนหมวดอื่น)
- สุ่มคำถามจากหมวดที่เลือกตามจำนวนที่ Admin ตั้ง (เช่น มี 20 ข้อ สุ่ม 10 ข้อ)
- จับเวลาต่อข้อ (ตั้งค่าได้จาก Admin)
- ตรวจคำตอบฝั่ง Server (ไม่ส่งเฉลยให้ Browser ก่อนตอบ)
- หน้าผลสรุปแสดง **จำนวนข้อที่ตอบถูก** + ผลผ่าน/ไม่ผ่าน
- ข้อความประชาสัมพันธ์และ QR Code (แก้ได้จาก Admin)
- เสียงประกอบ (เปิด/ปิดได้จาก Admin)

### Admin Dashboard (`/admin`)
- Login + Session Authentication (รหัสผ่าน Hash)
- Dashboard สรุปสถิติ
- CRUD หมวดหมู่ (เปิด/ปิด, จัดลำดับแสดงบนหน้าผู้เล่น)
- CRUD คำถาม + ตัวเลือก 2–6 ข้อ + คะแนนรายข้อ
- **ตั้งค่าเกม** รวม **เกณฑ์ผ่าน (%)** จำนวนข้อ เวลา ข้อความ ขนาดตัวอักษร QR
- ประวัติการเล่น + ค้นหา/กรอง + Export CSV
- เปลี่ยนรหัสผ่าน Admin

> **หมายเหตุ:** ไม่มีระบบรางวัล / Leaderboard / แข่งระหว่างผู้เล่น  
> ผ่านหรือไม่ผ่านดูจาก **เกณฑ์ผ่าน (%)** ในหน้าตั้งค่าเกมเท่านั้น

## ความต้องการของระบบ

- Python 3.8 ขึ้นไป
- ระบบปฏิบัติการ Windows / macOS / Linux

## วิธีติดตั้งและเปิดใช้งาน

### วิธีที่ 1: ดับเบิลคลิก (Windows)

1. ดับเบิลคลิกไฟล์ `run.bat`
2. รอให้ติดตั้ง dependencies (ครั้งแรก)
3. เปิด Browser ไปที่ลิงก์ที่แสดง

### วิธีที่ 2: ใช้ Command Line

```bash
cd quiz_system
pip install -r requirements.txt
python app.py
```

จากนั้นเปิด Browser:

| หน้า | URL |
|------|-----|
| ผู้เล่น | http://127.0.0.1:5000/player |
| Admin | http://127.0.0.1:5000/admin |

**บัญชี Admin เริ่มต้น**
- Username: `admin`
- Password: `admin123`

> แนะนำให้เปลี่ยนรหัสผ่านทันทีหลังจากเข้าสู่ระบบครั้งแรก

### เล่นจากเครื่องอื่นใน Wi‑Fi / LAN เดียวกัน

ระบบ bind ที่ `0.0.0.0` อยู่แล้ว หา IP ของเครื่องที่รัน (`ipconfig` / `ifconfig`) แล้วเปิดบนเครื่องอื่น:

```text
http://<IP-เครื่องรัน>:5000/player
```

## ข้อมูลตัวอย่าง

ระบบจะสร้างข้อมูลตัวอย่างให้อัตโนมัติเมื่อรันครั้งแรก:

- 3 หมวดหมู่: วิทยาศาสตร์, ประวัติศาสตร์, เทคโนโลยี
- คำถามหลายสิบข้อพร้อมตัวเลือกและเฉลย

สามารถแก้ไข/ลบข้อมูลตัวอย่างได้ทั้งหมดจากหน้า Admin

## กฎการเลือกหมวดและสุ่มคำถาม

1. ผู้เล่น**เลือกหมวดหมู่**จากรายการที่เปิดใช้งานบนหน้าแรก
2. ระบบสุ่มคำถาม **เฉพาะจากหมวดที่เลือก** ตามจำนวนที่ Admin ตั้ง
3. คำถามไม่ซ้ำภายในรอบเดียวกัน
4. หากหมวดมีคำถามไม่พอ:
   - `use_available` (ค่าเริ่มต้น): ใช้จำนวนที่มีจริง
   - `block`: ไม่เริ่มเกมและแจ้งเตือน

## เกณฑ์ผ่าน

- ตั้งที่ **Admin → ตั้งค่าเกม → เกณฑ์ผ่าน (%)**
- คะแนนที่ได้ ÷ คะแนนเต็ม × 100 ≥ ค่าที่ตั้ง = **ผ่าน**
- หน้าผลสรุปแสดงจำนวนข้อที่ตอบถูก และข้อความผ่าน/ไม่ผ่าน (แก้ข้อความได้จากตั้งค่าเกม)

## ความปลอดภัย

- คำตอบที่ถูกต้อง **ไม่ถูกส่งไปยัง Browser** จนกว่าผู้เล่นจะตอบแล้ว
- Backend ตรวจสอบคำตอบและคะแนนทั้งหมด
- ป้องกันการส่งคำตอบซ้ำ / ตอบข้อที่ไม่ใช่ข้อปัจจุบัน
- Admin API ต้อง Login ก่อนใช้งาน
- รหัสผ่านเก็บแบบ Hash (Werkzeug)
- ใช้ Parameterized Queries ป้องกัน SQL Injection

## การตั้งค่าสำคัญ (จาก Admin)

| รายการ | ค่าเริ่มต้น |
|--------|-------------|
| จำนวนคำถามต่อรอบ | 10 |
| เวลาต่อข้อ | 20 วินาที |
| เกณฑ์ผ่าน | 70% |
| แสดงเฉลยหลังตอบ | เปิด |
| เปิดเสียงประกอบ | ตามที่ตั้งในระบบ |
| ขนาดตัวอักษรหน้าผู้เล่น | ~1.12 |
| QR / ข้อความประชาสัมพันธ์ | แก้ได้ในตั้งค่าเกม |
| นโยบายคำถามไม่พอ | ใช้จำนวนที่มีจริง |
