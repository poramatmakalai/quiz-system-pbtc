# Local Quiz Management System

ระบบเกมตอบคำถามสำหรับใช้งานภายในหน่วยงาน ติดตั้งและรันบนคอมพิวเตอร์ได้ทันที โดยไม่ต้องเช่าโฮสต์ ไม่ต้องจดโดเมน และไม่จำเป็นต้องเผยแพร่ขึ้นอินเทอร์เน็ต

ออกแบบให้รองรับการใช้งานบนจอสัมผัสและงานประชาสัมพันธ์ ใช้โทนสีฟ้า–ขาวตามอัตลักษณ์วิทยาลัยเทคนิคเพชรบุรี

---

## 1. องค์ประกอบของระบบ

ระบบแบ่งเป็นสองส่วนชัดเจน ใช้ฐานข้อมูลร่วมกัน

| ส่วน | ที่อยู่ | ผู้ใช้ |
|------|--------|--------|
| เว็บไซต์ผู้เล่น | `/player` | ผู้เข้าเล่นเกม |
| แผงควบคุมผู้ดูแล | `/admin` | ผู้ดูแลระบบเท่านั้น |

ผู้เล่นไม่สามารถเข้าถึงหรือแก้ไขข้อมูลหลังบ้านได้

---

## 2. ฟีเจอร์หลัก

### 2.1 หน้าผู้เล่น

- กรอกชื่อได้ตามความสมัครใจ จากนั้นเลือกหมวดหมู่ที่ต้องการเล่น
- หมวดหมู่แสดงตามลำดับที่ผู้ดูแลกำหนด
- แต่ละรอบเล่นเพียงหนึ่งหมวด ไม่ปะปนคำถามข้ามหมวด
- ระบบสุ่มคำถามจากหมวดที่เลือก ตามจำนวนที่ตั้งไว้ (เช่น มี 20 ข้อ กำหนดให้เล่น 10 ข้อ)
- จับเวลาต่อข้อ และตรวจคำตอบที่เซิร์ฟเวอร์เท่านั้น ไม่เปิดเผยเฉลยก่อนตอบ
- หน้าสรุปผลแสดงจำนวนข้อที่ตอบถูก พร้อมสถานะผ่านหรือไม่ผ่านเกณฑ์
- รองรับข้อความประชาสัมพันธ์และคิวอาร์โค้ดหลังจบเกม (ตั้งค่าได้จากผู้ดูแล)
- มีเสียงประกอบ สามารถเปิดหรือปิดได้จากหน้าตั้งค่า
- ขนาดตัวอักษรและปุ่มออกแบบให้เหมาะกับจอสัมผัสตามมาตรฐาน ไม่ต้องปรับค่าเองจากหน้าผู้ดูแล

### 2.2 หน้าผู้ดูแลระบบ

- เข้าสู่ระบบด้วยบัญชีผู้ดูแล รหัสผ่านเก็บแบบเข้ารหัส
- แดชบอร์ดสรุปสถิติการใช้งาน
- จัดการหมวดหมู่ (เพิ่ม แก้ไข ลบ เปิด–ปิด และจัดลำดับการแสดงผล)
- จัดการคำถามและตัวเลือก (2–6 ตัวเลือกต่อข้อ) พร้อมคะแนนรายข้อ
- ตั้งค่าเกม ได้แก่ จำนวนข้อต่อรอบ เวลาต่อข้อ **เกณฑ์ผ่านเป็นเปอร์เซ็นต์** ข้อความต่าง ๆ เสียงประกอบ และการประชาสัมพันธ์
- ดูประวัติการเล่น ค้นหา กรองข้อมูล และส่งออกเป็นไฟล์ CSV
- เปลี่ยนรหัสผ่านผู้ดูแลได้ด้วยตนเอง

**สิ่งที่ระบบนี้ไม่มีโดยเจตนา**

- ระบบรางวัล
- ตารางจัดอันดับ (Leaderboard)
- การแข่งขันระหว่างผู้เล่น

การผ่านหรือไม่ผ่านเกณฑ์พิจารณาจาก **เกณฑ์ผ่าน (%)** ที่กำหนดในหน้าตั้งค่าเกมเท่านั้น

## 3. ความต้องการของระบบ

- Python เวอร์ชัน 3.8 ขึ้นไป
- ระบบปฏิบัติการ Windows, macOS หรือ Linux

---

## 4. การติดตั้งและเริ่มใช้งาน

### 4.1 บน Windows (แนะนำ)

1. ดับเบิลคลิกไฟล์ `run.bat`
2. รอให้ติดตั้งไลบรารีที่จำเป็นในครั้งแรก
3. เปิดเบราว์เซอร์ตามที่อยู่ที่โปรแกรมแสดง

ไฟล์ `run.bat` ไม่ต้องแก้ไขเพิ่ม ใช้เรียกติดตั้ง dependencies และรันโปรแกรมได้ตามปกติ

### 4.2 ผ่านบรรทัดคำสั่ง

```bash
cd quiz_system
pip install -r requirements.txt
python app.py
```

| หน้า | ที่อยู่ |
|------|--------|
| ผู้เล่น | http://127.0.0.1:5000/player |
| ผู้ดูแล | http://127.0.0.1:5000/admin |

**บัญชีผู้ดูแลเริ่มต้น**

- ชื่อผู้ใช้: `admin`
- รหัสผ่าน: `admin123`

ควรเปลี่ยนรหัสผ่านทันทีหลังเข้าสู่ระบบครั้งแรก

### 4.3 การใช้งานจากเครื่องอื่นในเครือข่ายเดียวกัน

โปรแกรมเปิดรับการเชื่อมต่อจากเครือข่ายภายในอยู่แล้ว หาหมายเลขไอพีของเครื่องที่รันระบบ แล้วเปิดจากเครื่องอื่นดังนี้

```text
http://<หมายเลขไอพีของเครื่องที่รัน>:5000/player
```

## 6. กฎการเล่นและการสุ่มคำถาม

1. ผู้เล่นเลือกหมวดหมู่จากรายการที่เปิดใช้งาน
2. ระบบสุ่มคำถามเฉพาะจากหมวดนั้น ตามจำนวนที่กำหนด
3. คำถามในรอบเดียวกันไม่ซ้ำ
4. หากจำนวนคำถามในหมวดไม่พอ
   - โหมดใช้จำนวนที่มีจริง (ค่าเริ่มต้น): เล่นเท่าที่มี
   - โหมดบล็อก: ไม่เริ่มเกมและแจ้งผู้เล่น

---

## 7. เกณฑ์ผ่าน

- กำหนดได้ที่ **ผู้ดูแล → ตั้งค่าเกม → เกณฑ์ผ่าน (%)**
- คำนวณจากคะแนนที่ได้เทียบกับคะแนนเต็ม หากถึงหรือเกินค่าที่ตั้ง ถือว่าผ่าน
- ข้อความเมื่อผ่านและเมื่อไม่ผ่านแก้ไขได้จากหน้าตั้งค่าเกม
- หน้าสรุปผลเน้นแสดงจำนวนข้อที่ตอบถูก ไม่เน้นคะแนนรวมหรือรายการผิด/หมดเวลา

---

## 8. ความปลอดภัย

ระบบออกแบบมาให้เปิดพอร์ตบนเครื่องภายในหน่วยงานได้ โดยมีมาตรการพื้นฐาน|

คำตอบที่ถูกต้องจะไม่ถูกส่งไปยังเบราว์เซอร์จนกว่าผู้เล่นจะตอบแล้ว การตรวจคะแนนทำที่เซิร์ฟเวอร์ทั้งหมด และใช้คำสั่งฐานข้อมูลแบบมีพารามิเตอร์เพื่อลดความเสี่ยงจากการโจมตีผ่านเอสคิวแอล

**ข้อแนะนำเพิ่มเติม**

- เปลี่ยนรหัสผ่านผู้ดูแลทันทีหลังติดตั้ง
- ใช้งานในเครือข่ายที่เชื่อถือได้ หากเปิดให้เครื่องอื่นเข้าถึง
- ไม่ควรเปิดโหมดดีบักขณะใช้งานจริง (หากต้องการเปิดชั่วคราวขณะพัฒนา ให้ตั้งค่า `FLASK_DEBUG=1` ก่อนรัน)

## 9. ค่าตั้งต้นที่สำคัญ

| รายการ | ค่าเริ่มต้น |
|--------|-------------|
| จำนวนคำถามต่อรอบ | 10 |
| เวลาต่อข้อ | 20 วินาที |
| เกณฑ์ผ่าน | 70% |
| แสดงเฉลยหลังตอบ | เปิด |
| นโยบายเมื่อคำถามไม่พอ | ใช้จำนวนที่มีจริง |

ข้อความประชาสัมพันธ์ คิวอาร์โค้ด และการเปิดใช้เสียง ปรับได้จากหน้าตั้งค่าเกม

---

## 10. ข้อมูลตัวอย่าง

เมื่อเปิดระบบครั้งแรก โปรแกรมจะสร้างข้อมูลตัวอย่างให้อัตโนมัติ ได้แก่ หมวดวิทยาศาสตร์ ประวัติศาสตร์ และเทคโนโลยี พร้อมคำถามตัวอย่าง ผู้ดูแลสามารถแก้ไขหรือลบข้อมูลเหล่านี้ได้ทั้งหมดจากแผงควบคุม

ฐานข้อมูลจัดเก็บที่ `database/quiz.db` ข้อมูลจะยังคงอยู่หลังปิดและเปิดโปรแกรมใหม่

---

## 11. หมายเหตุการใช้งาน

- หน้าผู้เล่นใช้สไตล์ชีตในเครื่อง ไม่พึ่งสคริปต์ภายนอกเป็นหลัก
- การดึงฟอนต์จากอินเทอร์เน็ตอาจใช้ได้เมื่อมีเครือข่ายในครั้งแรก ส่วนการทำงานหลักของระบบใช้แบบออฟไลน์ได้
- หน้าผู้เล่นและหน้าผู้ดูแลรองรับการแสดงผลบนหน้าจอขนาดต่างกัน
- ไฟล์ `run.bat` ใช้เปิดระบบบน Windows ได้โดยตรง ไม่ต้องแก้ก่อนใช้งาน
